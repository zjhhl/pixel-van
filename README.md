# 像素方块小车队 🚐

一款休闲解压的 HTML5 小游戏：像素画由一群会跑的小方块人组成，派出你的小货车，
把他们一批批接走，搬空整幅画就算过关！

纯 HTML5 Canvas + 原生 JavaScript，无任何依赖，打开即玩。

## 🎮 在线试玩

**[点击开始游戏](https://zjhhl.github.io/pixel-van/)** （GitHub Pages，手机/电脑均可）

## 玩法

- 点击**车队列首**的小货车，它会开到装货位
- 同色的小方块人会从画里跑出来，排队跳上货车
- 被**围住**的方块人上不了车——只有挨着「通道」（与底部连通的空格）的才能走
- 装**满 5 辆等货的车**还没货可装 → 堵车，失败！
- 搬空整幅像素画 → 过关，共 10 关

小技巧：点击装货位里「等货中…」的车可以撤回它，换别的车试试。

## 本地运行

```bash
git clone https://github.com/zjhhl/pixel-van.git
cd pixel-van
# 直接双击 index.html，或起一个静态服务器
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 调试参数

| 参数 | 说明 |
|---|---|
| `?level=5` | 直接进入指定关卡 |
| `?auto=1` | 自动派车（演示模式） |
| `?fast=N` | 同步快进 N 秒（截图/测试用） |
| `?debug=1` | 状态调试浮层 |

## 目录结构

```
index.html          入口
src/main.js         游戏逻辑（Canvas 渲染 + 状态机）
src/levels.js       关卡数据（脚本生成）
tools/build_levels.py   关卡底图 → 关卡数据转换
assets/             小车/小人/背景/UI/音效素材
docs/               素材生成规格文档
```

## 技术说明

- 关卡是一张小尺寸像素 PNG，按固定 14 色调色板逐像素解析成「颜色 → 方块数量」，
  再自动拆解成载货 5~30 的车队
- 无实拍小车的颜色（浅蓝/深绿/灰/棕/米）在运行时对白色车做 `source-atop` 染色
- 小方块人是程序绘制的 2.5D 立体造型 + 四段跑行动画（跳出格子 → 沿跑道奔跑 → 跳进车斗）
